# Workshop labs

This is the participant index for the repository's ordered workshop flow.
Complete readiness first. Lab 01 uses GitHub Copilot app Plan mode to produce
one human-approved durable specification. In Lab 04, choose either the Java
Asset Manager or .NET BookCatalog track and remain on that track; completing
both is not required. Labs 05-07 then use the same repository and evidence.

| Order | Lab | Outcome |
| --- | --- | --- |
| 1 | [00 — Readiness](00-readiness/) | Verify the Copilot app, shared tools, selected toolchain, and imported baseline. |
| 2 | [01 — Plan mode and durable specification](01-spec-driven-development/) | Use Plan mode to create and obtain human approval for one bounded repository specification. |
| 3 | [02 — Copilot instructions](02-copilot-instructions/) | Trace the instruction hierarchy and verify matching and non-matching behavior. |
| 4 | [03 — Custom agents and skills](03-custom-agents-and-skills/) | Create bounded, reusable agent and skill assets. |
| 5 | [04 — Application modernization](04-app-modernization/) | Use Modernize CLI for assessment and technical planning, then review Upgrade-agent execution and locally validate [Java](04-app-modernization/java/) or [.NET](04-app-modernization/dotnet/). |
| 6 | [05 — Agentic SDLC](05-agentic-workflows/) | Compile and inspect guarded `gh-aw` issue-to-backlog and issue-to-PR workflows. |
| 7 | [06 — Automated QA](06-automated-qa/) | Keep deterministic CI authoritative while adding advisory QA and bounded remediation. |
| 8 | [07 — Capstone](07-capstone/) | Demonstrate a validated modernization, public-service starter, or agentic-workflow slice. |

At a high level, repository-wide guidance, matching path-specific
instructions, and root or local `AGENTS.md` files work together. Do not assume
automatic precedence; [Lab 02](02-copilot-instructions/) provides the detailed
trace and conflict-handling exercise.

Return to the [repository overview](../README.md) for event details,
prerequisites, source locations, Azure ownership/cleanup rules, and the
facilitator and validation links.
