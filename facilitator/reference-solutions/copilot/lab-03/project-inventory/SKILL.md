# Project inventory

Select exactly one application root. Read its nearest README, build manifest,
module/project declarations, source and test directory names, and applicable
Copilot instructions.

Report:

1. technology and target/runtime version;
2. modules or projects;
3. production and test roots;
4. direct dependency declarations;
5. documented validation command and working directory; and
6. missing evidence or prerequisites.

Do not inspect the alternative language track, read credential files, recurse
into generated output or package caches, run restore/build/test, or change
files. Cite every conclusion with a repository-relative path.
