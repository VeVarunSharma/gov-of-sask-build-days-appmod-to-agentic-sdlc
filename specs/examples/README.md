# Completed specification examples

These examples demonstrate a small, modernization-relevant scope. They are
reference specifications shaped as the single durable artifact required by
Lab 01, not instructions to modify the imported baselines.

- [Java: enforce the documented image upload policy](java-upload-validation.md)
- [.NET: remove request-specific browser diagnostics](dotnet-remove-user-agent.md)

Each example includes evidence, an execution boundary, acceptance criteria,
validation, exclusions, stop conditions, and a Plan-mode review checkpoint.
Their approval fields deliberately state that they are reference-only; a real
change requires a named human reviewer, date, and approved commit before its
intent can be transferred into the
[autonomous issue body](../templates/autonomous-issue-body.md).
